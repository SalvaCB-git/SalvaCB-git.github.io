Sudoku solver

This is the C++ code of a Sudoku exercise from a university group project, compiled to WebAssembly. A build-time patch adds one logging call where a digit is placed or removed; the search itself is not changed. Watch it backtrack in your browser. The puzzle you type is not sent anywhere.

Digit just placed · Digit just removed

Type digits into the grid or load another example, then solve. Arrow keys move between cells; Backspace or Delete clears one. The original looks for every solution, so a puzzle with few clues can run for a very long time; Stop ends it. It does not check the given digits, so clashing clues can still produce a grid that breaks the rules.

A step is one digit placed or removed by the original's addCasillaRellena or deleteCasillaRellena. Wall time is one run in this browser, including recording the steps and excluding loading the WebAssembly; it will vary.

Exercise example is the puzzle from the exercise's main.cpp. The new examples come from a separate script written for this page, not from the exercise. Each has one solution, and Easy, Medium and Hard mean 40, 32 and 27 clues; that is not a measure of how long the search takes.
